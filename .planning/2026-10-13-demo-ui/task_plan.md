# PDF Demo 前端方案

目标：面向研发调试和人工审核，提供设计文档、页面草图、API 契约和分阶段实施建议。本轮不实现业务代码。

- [x] 核对现有实现、审查报告与合同。

- [x] 核对官方前端/PDF/API 文档。
- [x] 形成页面、交互、结果状态和证据坐标设计。

## 决策

- 首版桌面浏览器、本地单用户；延续 Python 解析核心、SQLite 和不可变制品。
- 前端独立，通过 HTTP API 与后端通信；不引入新的工作流框架。
- 先修复审查发现的完整流程/证据/评测问题，再宣称真实闭环完成。

## 错误

- `.planning/` 初始不存在，rg 清单报路径不存在；创建本任务独立规划目录。
- 批量读取的输出超长截断；后续按范围读取并限制输出。
- 草图浏览器检查：bundled Playwright 缺少默认 Chromium 可执行文件；改用已安装浏览器通道，不下载新浏览器。
